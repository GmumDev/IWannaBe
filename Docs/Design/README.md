## 확정 사항

2026-10-08 기준.

| 항목 | 결정 |
|---|---|
| 컨셉 | "I wanna be ___". 오타마톤이 되고 싶은 것(꿈)을 미니게임으로 하나씩 체험한다 |
| 장르 | 리듬세상류 원버튼 리듬 게임 |
| 챕터 | 미니게임 4 + 리믹스 1. 출시 시 4챕터(미니게임 16 + 리믹스 4 = 20스테이지) |
| 플랫폼 | PC(Steam, Stove)와 모바일(Google Play) 동시 출시 |
| BM | PC는 유료 본편 + DLC, 모바일은 무료 시작 + 정식판 해금. 상품 목록은 플랫폼 공통 |
| 운영 | 출시 후 확장팩(새 챕터) 중심. 시즌 패스는 출시 범위 밖이며, 여력이 생기면 모바일에서만 검토 |
| 광고 | 모바일 보상형 광고만, 출시 후 업데이트로 도입 |
| 내 음악으로 플레이 | PC 전용, 본편에 포함 |
| 로비 | 오타마톤의 방. 보유 슬롯 수만큼 오타마톤이 방에서 지낸다 |
| 오타마톤 슬롯 | 처음 1개, 챕터 클리어마다 +1, 판매하지 않음. 새 슬롯은 보유 아이템의 랜덤 조합으로 시작 |
| 가구 배치 | 정해진 자리마다 하나씩 고르는 방식 |
